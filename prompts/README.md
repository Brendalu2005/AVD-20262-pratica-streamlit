# Prompts

Organizei nesta pasta os arquivos de apoio ao uso de IA no meu projeto:

1. **Rascunhos de layout:** mantenho os arquivos oficiais em `entregas/rascunho-dashboard1.png` e `entregas/rascunho-dashboard2.png`. Apresento as revisões de 02/11/2026 como posteriores à implementação e preservo a proposta inicial em `entregas/proposta-inicial-spotify.png`.
2. **Template de prompt do rascunho → esqueleto:** organizo o [layout-skeleton-prompt.md](layout-skeleton-prompt.md) em quatro blocos: Contexto, Entrada, Restrições e Formato de saída. Essa versão revisada descreve a estrutura atual e não é uma transcrição do prompt original.
3. **Registro de Uso de IA:** reúno em [declaracao-uso-ia.md](declaracao-uso-ia.md) resumos das minhas solicitações, contribuições recebidas, decisões e verificações. Não apresento esses resumos como transcrições literais.

O modelo formal fornecido pela disciplina exige também o PDF individual
preenchido e assinado em `prompts/DECLARACAO_IA.pdf`, com entrega no Classroom.
Uso este Markdown como apoio ao preenchimento; ele não substitui meu formulário,
minha reflexão individual nem minha assinatura. Declaro no registro o uso da
skill oficial do Streamlit. Mantenho as marcações `[IA]` nos blocos complexos;
reconheço que são parciais e não identificam todos os trechos com apoio de IA.

Para completar a entrega, preciso reunir as conversas ou preencher os blocos
do formulário com os usos relevantes e as verificações correspondentes,
distinguindo os testes que realizei dos testes executados com apoio do Codex.

Mantenho os rascunhos versionados como parte da entrega.
