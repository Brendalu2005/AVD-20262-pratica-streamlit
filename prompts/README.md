# Prompts

Esta pasta serve para três propósitos:

1. **Rascunho do layout**: os arquivos oficiais ficam em `entregas/rascunho-dashboard1.png` e `entregas/rascunho-dashboard2.png`, conforme o roteiro. Mostre a sidebar e cada bloco de conteúdo. As revisões de 02/11/2026 estão identificadas como posteriores à implementação; a proposta inicial foi preservada em `entregas/proposta-inicial-spotify.png`.
2. **Template de prompt do rascunho → esqueleto**: [layout-skeleton-prompt.md](layout-skeleton-prompt.md) traz o template de 4 blocos (Contexto, Entrada, Restrições, Formato de saída). Preencha com o caminho do seu rascunho, anexe a imagem e envie à ferramenta de IA.
3. **Registro de Uso de IA**: [declaracao-uso-ia.md](declaracao-uso-ia.md) contém resumos das solicitações reais, contribuições, escolhas registradas e validações. Os resumos não são transcrições literais nem prompts criados depois para representar um uso diferente.

O modelo formal fornecido pela disciplina exige também o PDF individual
preenchido e assinado em `prompts/DECLARACAO_IA.pdf`, com entrega no Classroom.
Este Markdown auxilia o preenchimento e não substitui o formulário, a reflexão
individual nem a assinatura. O uso da skill oficial do Streamlit está declarado
no registro. As marcações `[IA]` no código se concentram nos blocos complexos;
são parciais e não demonstram, por si só, o
cumprimento da exigência de identificar todos os trechos com apoio de IA.

Dica: preserve as conversas originais para consulta e eventual anexação. Se optar
pelo registro por blocos no formulário, complete os usos relevantes e a forma
como você mesma conferiu os resultados, sem atribuir a si testes feitos pela IA.

Os rascunhos fazem parte do entregável: não os coloque no `.gitignore`.
